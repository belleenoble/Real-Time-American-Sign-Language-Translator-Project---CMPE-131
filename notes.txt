convert_images.py: use this if you want to train using online data (image files) instead of with your own hands

	put this in the workspace terminal:

	python convert_images.py "dataset\[put your dataset folder name here]" --workers 8 --force 

	then enter, the worker command is to speed up the process, the maximum is 8 and can be lower if computer can't handle it.
